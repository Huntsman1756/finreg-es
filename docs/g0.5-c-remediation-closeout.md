## 3. Diagnósticos LEI (G05-B-F03) — versionados

`FINREG_LEI_DIAGNOSTIC_V2` en `finreg_es/identity.py` separa lo que la
validez booleana mezclaba:

```text
VALID | MISSING | INVALID_LENGTH | INVALID_CHARSET | INVALID_CHECK_DIGITS
```

Capa agregada conservada: `is_valid_lei` ≡ `lei_diagnostic == "VALID"`.
El checksum sólo se evalúa cuando longitud y alfabeto lo permiten
(G05-012 → `INVALID_LENGTH`; G05-015 → `INVALID_CHECK_DIGITS`).

Regla de identidad sin cambios:

```text
invalid LEI
→ preserve raw value
→ never silently repair
→ prohibit LEI-based automatic join
→ allow exact resolution through another authoritative identifier
```

Un checksum inválido no implica por sí mismo `AMBIGUOUS_IDENTITY`.
